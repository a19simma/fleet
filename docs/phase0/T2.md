## Result

Pass. Every field the plan lists exists: `prompt`, `last_assistant_message`, `notification_type`, `message`.

## Plan impact

- Normalizer field list: common = `session_id, transcript_path, cwd, hook_event_name`; `prompt_id` on all but a failed-start SessionEnd; UserPromptSubmit adds `prompt, permission_mode`; Stop adds `last_assistant_message, stop_hook_active, permission_mode, effort, background_tasks, session_crons`; SessionEnd adds `reason`; Notification adds `message, notification_type`. Keep verbatim `raw`.
- `prompt_id` is a useful join key across UserPromptSubmit, Stop, Notification and SessionEnd within one turn. Consider using it as the Event correlation id.
- Stop carries `last_assistant_message` directly, so the transcript read is only needed for the timeline (matches the plan fallback).
- `permission_mode` differs: `auto` in `-p` on the box, `default` in an interactive run with the flag. Do not rely on it.
